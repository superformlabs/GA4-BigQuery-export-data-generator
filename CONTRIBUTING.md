# How to help

Thank you for wanting to. This repository is a one-way copy, so there is one
way in and it is short.

## Pull requests are not accepted

This repository holds the generator the Superform Labs GA4 BigQuery Export
Data Generator app uses, copied here from a private working repository at
each release. Nothing is written here, so a pull request could not be merged,
and pull requests are switched off. The GPL lets you fork this repository
and change your copy as much as you like.

## Found a bug? Tell us with the form

[Report a bug](https://github.com/superformlabs/GA4-BigQuery-export-data-generator/issues/new?template=bug-report.yml).
It is the only kind of issue this repository takes, and we read every one. A
bug in the app and a bug in the generator are both welcome. A good report says
what happened, what you expected, and which page you were on.

**Please do not write private details in an issue.** It is readable by
everyone, now and later. No Google Cloud project ID, no dataset name, no
email address, and no key, token or password. We can act on a report without
them.

## Something private, or not a bug?

Write to support@superformlabs.eu. Use that address for anything that should
not be public, and for questions that are not bug reports.
